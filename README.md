## Собственный проект

Тема проекта: Коллекция фильмов

Главный класс: Фильм

Почему этот объект нужен программе:
Чтобы программа работала и выводила коллекцию фильмов.

Какие данные хранит объект:

- Название
- Дату создания
- Жанр
- Оценку

Какие значения задаются через конструктор:
Название, Дата создания фильма, его жанр и оценка в 10 бальной шкале.

Какое значение я решила задавать автоматически и почему:
Доступность фильма, потому что это значение для всех фильмов одинаково.

# Практическая 2

Добавлен метод `UpdateRating` для изменения оценки фильма.

Параметр `newRating` получает новую оценку фильма типа данных `Double`.

Проверенный отказ значения вне диапазона от 0 до 10.Начальный рейтинг `8.6` после изменения на `9.2` стал `9.2`, и после попытки установить `15.0` остался прежним (`9.2`).

1. Почему при `yaroslav.TakeDamage(25);` не меняется здоровье Артёма и куда попадает 25?
Потому что метод вызван у объекта `yaroslav`, поэтому он меняет только его собственное поле `Health` и не трогает других героев. А число 25 при вызове записывается в параметр `damage` внутри метода `TakeDamage`.

2. Чем отличаются `return`; в `TakeDamage` и `return Health > 0;` в `IsAlive`?
* `return` используется для досрочного прерывания работы
* `return Health > 0;` вычисляет и возвращает результат типа bool в место вызова метода.

3. Как получить строку о герое, не печатая её сразу, и какая строка печатает её позже?
Строку можно сохранить в переменную `string info = yaroslav.GetInfo();`, так как сам метод `GetInfo` только формирует текст, но не выводит. Печать выполняется отдельной командой `Console.WriteLine(info);`.

Появились пять методов - `TakeDamage`, `Heal`, `GainExperience`, `IsAlive` и `GetInfo`.

Проверка недопустимого урона выполнена вызовом `yaroslav.TakeDamage(-20)`; с помощью `damage <= 0` и раннего `return;`.
