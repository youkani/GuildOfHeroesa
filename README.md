1. Почему при `yaroslav.TakeDamage(25);` не меняется здоровье Артёма и куда попадает 25?
Потому что метод вызван у объекта `yaroslav`, поэтому он меняет только его собственное поле `Health` и не трогает других героев. А число 25 при вызове записывается в параметр `damage` внутри метода `TakeDamage`.

2. Чем отличаются `return`; в `TakeDamage` и `return Health > 0;` в `IsAlive`?
* `return` используется для досрочного прерывания работы
* `return Health > 0;` вычисляет и возвращает результат типа bool в место вызова метода.

3. Как получить строку о герое, не печатая её сразу, и какая строка печатает её позже?
Строку можно сохранить в переменную `string info = yaroslav.GetInfo();`, так как сам метод `GetInfo` только формирует текст, но не выводит. Печать выполняется отдельной командой `Console.WriteLine(info);`.

### Поведение главного класса

Метод 1: `UpdateRating(double newRating)`
Что делает: проверяет, что новая оценка находится в диапазоне от 0 до 10, и обновляет `Rating`.

Метод 2: `ChangeStatus(string newStatus)`
Что делает: проверяет, что переданная строка не пустая, и меняет статус фильма.

Метод 3: `IsTopRated()`
Что возвращает:  `true`, если текущий рейтинг фильма равен или превышает `8.0`, и `false` в противном случае.

Почему эти действия относятся именно к этому классу:
Потому что пользователь обновляет оценки после просмотра, отмечает просмотренные фильмы и отбирает лучшие с высоким рейтингом.

### Дополнительные вопросы по своему коду

1. Что такое метод экземпляра и чем он отличается от поля?
Метод экземпляра это действие внутри класса, описывающее объект и работающее с его полями. Поле это переменная внутри класса, которая хранит состояние объекта.
* Поля:
```cs
public class Film {
    public string Name;
    public int Data;
    public string Genre;
    public double Rating;
    public string Status;
}
```
* Методы:
```cs
public void UpdateRating(double newRating) {
    if (newRating < 0 || newRating > 10) {
        return;
    }
    Rating = newRating;
}
public void ChangeStatus(string newStatus) {
    if (newStatus.Length == 0) {
        return;
    }
    Status = newStatus;
}
public bool IsTopRated() {
    return Rating >= 8.0;
}
```

2. Как значение при вызове попадает в параметр?
При вызове метода значение, написанное в скобках, копируется в переменную, объявленную в заголовке метода.
* Вызов: `interstellar.ChangeStatus("Просмотрен");`
* Заголовок метода: `public void ChangeStatus(string newStatus)`

3. Что означает `void`?
Означает, что метод выполняет действие, но не возвращает результат в место вызова.

4. Чем отличаются `return;` и `return Health > 0;`?
`return;` досрочно прерывает выполнение кода и ничего не возвращает. `return Health > 0;` сначала вычисляет результат, а потом передаёт ответ в место вызова метода.

5. Какие значения возвращает `bool` и как сохранить ответ `IsAlive()`?
`bool` возвращает `true` или `false`. Чтобы сохранить ответ, нужно объявить переменную типа bool и присвоить ей результат вызова метода со скобками.
* `bool yaroslavAlive = yaroslav.IsAlive();`

6. Почему `GetInfo()` возвращает строку, а вывод выполняется в `Program.cs`?
`GetInfo()` только подготавливает данные а в `Program.cs` решается когда и куда их вывести. Это нужно чтобы разделить логику объекта и работу с консолью.
* Метод формирует текст: `string info = yaroslav.GetInfo();`
* Вывод: `Console.WriteLine(info); `

7. Почему один метод изменяет состояние только того героя, у которого вызван?
У каждого объекта свои поля. Когда написано имя объекта, метод получает доступ именно к нему и не затрагивает другие объекты того же класса.
* `interstellar.UpdateRating(9.2);` interstellar это имя конкретного объекта и оно пишется слева от точки, а после идёт вызов метода.

8. Как внешний код пока может обойти проверки методов?
Все поля объявлены с `public` то есть открыты для всех. Любой код в `Program.cs` может обратиться к такому полю.
* Обход проверки в TakeDamage: `yaroslav.Health = -5000;`

## Практическая 3

* Ошибка 1: публичный сеттер `public int Health { get; set; }` позволял менять здоровье извне → изменено на `public int Health { get; private set; }` → при попытке присвоить `alexander.Health = -100;` возникает ошибка компиляции, чтение работает.

* Ошибка 2: вызов `value.Trim();` без сохранения результата оставлял пробелы в имени → изменено на `_name = value.Trim();` → проверка через `Hero(" Александр ", 150)` вывела `[Александр]`.

1. Чем отличается запрет внешней записи от проверки допустимого числа? Где проверяются здоровье при создании и его изменение?

`private set` у свойства `Health` запрещает прямой доступ снаружи (из `Program.cs`), но не проверяет значения. Допустимость чисел проверяется внутри `Hero`: в конструкторе `Hero(string name, int health)` при создании и в методах `TakeDamage` и `Heal` при изменении.

2. Как `Name = name;` связывает параметр конструктора, `value` и поле `_name`?

`name` передаётся в `private set` свойства `Name` как встроенная переменная `value`, очищается от пробелов через `value.Trim()` (или заменяется на `"Безымянный герой"`) и сохраняется в закрытое поле `_name`.

3. Какие значения в проверках показали, что правило `0 <= Health <= MaxHealth` соблюдается?

При создании объектов значения `-100` и `5000` превратились в `0/100` и `200/200`. Для Александра (`150/150`) вызов `Heal(5000)` остановился на `150`, `Heal(-20)` оставил `150`, а `TakeDamage(5000)` снизил здоровье ровно до `0`.

### Самостоятельный шаг

* **Выбранное правило:** рейтинг фильма находится в диапазоне от `0.0` до `10.0`, внешняя прямая запись запрещена через `private set`.
* **Где проверяется:** в конструкторе `Film` (ограничивает начальное значение диапазоном) и в методе `UpdateRating` (отклоняет значения меньше `0` или больше `10` через ранний `return;`).
* **Входные и фактические значения при неправильном действии:** для фильма «Интерстеллар» с исходным рейтингом `8,7` попытка вызвать `UpdateRating(15.0)` оставила рейтинг `8,7`, допустимый вызов `UpdateRating(10.0)` изменил его на `10`, а последующая попытка `UpdateRating(-5.0)` оставила значение `10`.
